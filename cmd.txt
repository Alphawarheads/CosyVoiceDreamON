版本 tag 约定
============
训练程序目前没有单独的 --tag 参数。每次新实验先定义一个唯一的 RUN_TAG，并将它同时用于
model_dir、tensorboard_dir、生成目录和评测目录。checkpoint 自带 epoch、训练配置和基础模型路径；
RUN_TAG 负责区分不同实验版本。推荐格式：日期_方法_数据_初始化_关键参数，例如：

RUN_TAG=20260911_lora_r16_train100_scratch

不要复用已经训练过的 RUN_TAG，否则 checkpoint 和 TensorBoard 事件可能混入旧结果。
下面旧的 freeze/unfreeze 命令保留了固定目录名；每次重跑时也应把目录名改成新的 RUN_TAG。

六、评测清单和 checkpoint
=========================
四个实验必须使用同一份 data/eval/eval.meta.lst，格式：
utt|prompt_text|prompt_wav|target_text|target_wav

正式生成时 output-dir 必须是不存在的新目录。epoch_0_whole.pt 只是示例；应查看每个 epoch
的 dev CV loss，改用最好的 epoch_N_whole.pt。当前训练没有自动 early stopping。

freeze checkpoint 保存投影层，DreamOn/CosyVoice/Flow/HiFT 从原权重目录加载。
unfreeze checkpoint 保存完整 DreamOn 主干和投影层。原始权重目录不会被覆盖。


七、LoRA：从原始 DreamOn/CosyVoice 权重重新训练
==============================================
LoRA 使用原生 PyTorch 实现，无需额外安装 peft。
--freeze_dreamon true --use_lora true：冻结原始主干，训练内部 LoRA 和两个投影层。
不要与 --freeze_dreamon false 同用，后者是全量微调。

默认覆盖各层 q_proj/k_proj/v_proj/o_proj，rank=16、alpha=32、dropout=0.05。
LoRA LR=1e-4，投影层 LR=1e-4；这些是起始配置，效果需要验证。
原始主干保持 BF16，LoRA 和投影层保持 FP32 可训练权重，前向使用 BF16 AMP。
按本地 DreamOn 配置计算：LoRA 10,092,544 参数，两个投影层 6,422,528 参数，
合计 16,515,072 可训练参数。启动日志会显示实际数量和主干 dtype。

两卡训练：将命令开头改为 CUDA_VISIBLE_DEVICES=0,1 NPROC_PER_NODE=2。
DDP 每张卡保留完整模型；相同 per-GPU batch_size 下加卡会增大全局 batch。
预处理直接复用，不必重新提取语音 token。
以上两条命令都不传 --checkpoint，因此 DreamOn、CosyVoice 语音组件和两个投影层均从
原始模型及固定随机种子初始化，epoch 从 0 开始；不会继承此前冻结实验的投影权重。
继续同一次 LoRA 实验：checkpoint 换成该实验的 epoch_N_whole.pt，去掉 --weights_only，
保留 --use_lora true 及相同 rank/alpha/dropout/target_modules。
当前 checkpoint 不包含优化器状态，继续训练会重建 Adam，不是精确恢复中断状态。
若要改变 LoRA 结构配置，应从原冻结 checkpoint 新开实验。
旧版全量解冻 checkpoint 不能直接加载到已安装 LoRA 的主干。

生成时从 checkpoint 自动恢复 LoRA，无需指定 --use_lora。每次生成使用新的 output-dir。
meta 必须是 utt|prompt_text|prompt_wav|target_text[|target_wav] 清单，不能用 dev_all.data.list。
评测仍需事先安装 seed-tts-eval 及其依赖，音频生成不依赖该评测仓库。

LoRA epoch_N_whole.pt 使用 format_version=4，保存完整 DreamOn 主干、未合并 LoRA、
两个投影层及 LoRA 配置。不是仅保存 LoRA 的小文件，不会覆盖原始基座权重目录。
完整 checkpoint 的磁盘占用及保存时 CPU 内存仍然较大。
CosyVoice 语音 embedding/head、Flow、HiFT 继续从 CosyVoice2-0.5B 目录加载。
需要同步新版代码后再读取 LoRA checkpoint。原来冻结/全量模式的旧 checkpoint 仍可使用。
实际训练显存与 GPU、序列长度等有关，不能仅按可训练参数比例估算，也不能保证单卡 48GB 一定够。
